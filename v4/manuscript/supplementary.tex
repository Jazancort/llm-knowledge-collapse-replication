\section*{Table S1: Base-Model Checkpoint Identifiers}
% ─────────────────────────────────────────────────────────────────────────────

All three backbones were retrieved from the Hugging Face Hub without an explicit
\texttt{revision=} argument; the loaded revision is therefore determined by the
snapshot present in the local cache at the time of each experiment.
The cache snapshot identifiers (commit SHA-1 hashes of the model repository
at download time) are listed below and are sufficient to retrieve the identical
weights from the Hub.
The identifier for Gemma~4~E2B~IT reflects the snapshot downloaded on
2026-06-26 and present in cache when the Gemma~4 experiments were executed
(2026-06-27); a second snapshot (\texttt{3e22461}) was downloaded to the same
cache on 2026-09-30 but was not used in any reported experiment.
